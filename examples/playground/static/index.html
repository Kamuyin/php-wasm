      WASI Preview1 limitations & available features
      

        
✓Core PHP & all standard library functions

        
✓JSON encode / decode

        
✓mbstring (Unicode, multibyte)

        
✓PDO + SQLite (in-memory)

        
✓bcmath, calendar, tokenizer

        
✓Closures, generators, fibers API stub

        
✓Date/time (system clock available)

        
✓Filesystem reads/writes to /tmp

        
✗Networking (TCP/UDP) — no WASI socket API

        
✗Fibers / coroutines — no ucontext in WASM

        
✗fork / popen / proc_open — stubbed as ENOSYS

        
✗Opcache / JIT — no RWX memory in WASM

        
✗Threads (pthreads / parallel)

        
~Extensions vary by profile (minimal / default / full)
